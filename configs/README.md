# Configuraciones Cisco

Aquí se incorporarán exportaciones **sanitizadas** de las configuraciones de R1, SW1 y SW2.

Antes de publicarlas, eliminar o reemplazar:
- Comunidades SNMP.
- Usuarios, contraseñas y claves.
- Cadenas de autenticación y cualquier otro secreto.
- Avisos/licencias propietarios que no corresponda redistribuir.

Aún no se han subido exportaciones definitivas.
